Example: Supervised Learning using K-Nearest Neighbors (KNN) Algorithm

Supervised Learning → model learns from labeled data to predict outcomes for new data

Problem: Predict whether a student will Pass or Fail based on study hours.

from sklearn.neighbors import KNeighborsClassifier
model = KNeighborsClassifier(n_neighbors=3)
model.fit([[2],[4],[6],[8]], ["Fail","Fail","Pass","Pass"])
prediction = model.predict([[5]])
print(prediction)

output: ['Fail']

The model learned:

Study Hours → Result

2 hours → Fail
4 hours → Fail
6 hours → Pass
8 hours → Pass

Now we ask:

prediction = model.predict([[5]])

The model checks the 3 nearest neighbors (n_neighbors=3):

New student = 5 hours

Nearest examples:

4 hours → Fail  (distance = 1)
6 hours → Pass  (distance = 1)
2 hours → Fail  (distance = 3)

Voting:

Fail = 2 votes
Pass = 1 vote

So KNN predicts:

5 hours → Fail

To make the prediction "Pass", change the number of neighbors:

from sklearn.neighbors import KNeighborsClassifier

model = KNeighborsClassifier(n_neighbors=2)
model.fit([[2],[4],[6],[8]], ["Fail","Fail","Pass","Pass"])

prediction = model.predict([[5]])
print(prediction)

Output: ['Pass']

Key Learning:

KNN does not learn a fixed rule like:

Above 5 hours = Pass

Instead, it asks:

"Which previous examples are closest to this new example?"

and predicts based on their majority vote.

This is why KNN is called a lazy learning algorithm — it stores the examples and makes decisions during prediction time.

Example: Supervised Learning using Logistic Regression Algorithm

Supervised Learning → model learns from labeled data to predict outcomes for new data

Problem: Predict whether an email is Spam or Not Spam based on the number of suspicious words.

from sklearn.linear_model import LogisticRegression
model = LogisticRegression()
model.fit([[1],[2],[8],[10]], ["Not Spam","Not Spam","Spam","Spam"])
prediction = model.predict([[7]])
print(prediction)

output : ['Spam']

Explanation:

The model learns from labeled examples:

Suspicious Words → Email Type

1 word  → Not Spam
2 words → Not Spam
8 words → Spam
10 words → Spam

For a new email:

7 suspicious words → Model predicts "Spam"

Unsupervised Learning --> model learns from unlabeled data to find hidden patterns, groups or relationships.

from sklearn.cluster import KMeans
model = KMeans(n_clusters=2)
model.fit([[1,2],[2,3],[8,9],[9,10]])
print(model.labels_)

[1 1 0 0]

Explanation:

The model receives unlabeled data (only numbers, no answers).
It automatically groups similar data points into 2 clusters.
